录制时插入独立的 CVE 演示夹具并新增一个 Maven 组件，结束时清理夹具和相关日志，不删除或改写教师记录。录屏中的漏洞总数可能暂时为 1001，这是演示夹具，不是重复导入。

启动章节展示本次真实 Docker ps 与启动日志，避免将等待镜像下载的大量时间放进课程演示。HTTP 面板由录制脚本临时插入浏览器，只展示实际捕获的数据，不属于产品页面，也不是模拟响应。

## 重新录制

先确保服务健康，并在 app 容器安装浏览器：

```sh
docker compose up -d --wait --wait-timeout 300
docker compose exec app npm run browser:install
mkdir -p tmp
docker compose ps > tmp/demo-startup.log
docker compose logs --no-color --tail 20 app >> tmp/demo-startup.log
docker compose exec app npm run demo:record
```

会更新 docs/项目演示.webm、docs/demo-http.json 和 docs/images/ 中的截图。临时视频与浏览器下载位于 tmp/。脚本运行约六分钟，按章节输出进度；不要在录制过程中重复启动或重建 app。旧录屏会被新录屏替换。

## 现场操作建议

Windows PowerShell 建立 SSH 转发后，打开 localhost:5173。按照 README 操作；浏览器 F12 → Network 可以直接展示一次 PATCH 或 DELETE。演示教师指定记录时，先说明删除不可撤销，选择演示专用记录更便于复现。CVE 不提供新增 API，测试夹具由测试工具直接准备，不是面向用户的新功能。

如果教师要求学生本人录屏讲解，使用本机录屏工具录制浏览器和终端，并按上述脚本讲解。当前自动录屏提供功能证据，不能代替本人理解关键代码。
